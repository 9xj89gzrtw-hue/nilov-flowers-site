# Nilov Flowers — S2: Next.js витрина + админка (деплой-инструкция)

> S2 — глубокая модернизация: живая БД (Prisma/SQLite), светлая витрина уровня 5cv.ru,
> Kanban-админка для флористов. Работает в этом репозитории рядом с legacy-кодом
> (PHP-эра + v2026) — прод на SpaceWeb (Apache) продолжает обслуживаться старым кодом,
> пока владелец не перенесёт S2 на Node-хостинг.

## Быстрый старт (dev)

```bash
bun install                 # зависимости
bun run db:push             # применить prisma/schema.prisma к SQLite
bun scripts/seed.ts         # 24 букета, 14 зон СПб, апселлы, настройки, промокоды
bun run dev                 # http://localhost:3000 — витрина
```

- **Панель флориста:** `http://localhost:3000/#admin` — пароль по умолчанию `nilov2026`
  (меняется в «Сайт» → «Пароль администратора»).
- **БД:** `db/flowers.db` (gitignored; `DATABASE_URL` в `.env`).
- **Фото букетов:** `img/products/` — в dev раздаются через симлинк `public/img → ../img`.

## Структура S2

```
src/app/page.tsx            — витрина (SSR из живой БД)
src/app/api/…               — публичные и админ-роуты (JSON)
src/components/store/…      — витрина: шапка, поиск, чипсы, карточки, корзина, чекаут
src/components/admin/…      — админка: канбан заказов (dnd-kit), каталог, зоны, настройки
src/lib/                    — db (Prisma-синглтон), store (zustand), types, admin-auth, rate-limit
scripts/seed.ts             — сид из реальных источников (v2026/content.json + PHP seed)
prisma/schema.prisma        — Product/Order/OrderItem/DeliveryZone/Upsell/Setting/PromoCode
```

## Продакшн на Node-хостинге (цель ≤ 1 ГБ RAM)

1. `next build` (standalone-выход уже настроен) → `node .next/standalone/server.js`.
2. **Важно (замер критика 5):** скопировать `img/` в `public/img` физически — симлинк
   и загрузки рассчитаны на дев; папку загрузок задать через абсолютный путь или
   `NF_IMG_DIR`, БД — через `DATABASE_URL`.
3. Env: `NF_SESSION_SECRET` (уникальная строка), `NODE_ENV=production` (куки Secure за HTTPS).
4. Ожидаемый RSS прод-процесса — 150–300 МБ (Turbopack-dev ест ~1.4 ГБ — это норма только для разработки).
5. SQLite: включить WAL, настроить регулярный бэкап `db/flowers.db` + `img/uploads/`.
6. Rate-limit и Cache-Control уже встроены (см. `src/lib/rate-limit.ts`).

## Что умеет S2 (кратко)

- Витрина: живой поиск, липкие фильтры-чипсы (цены + теги), карточки 3:4 с hover-зумом,
  «Купить в 1 клик», корзина с прогрессом бесплатной доставки, апселлы (открытка/Кризал 0 ₽),
  промокоды, чекаут без перезагрузки (сюрприз/самовывоз/«узнать адрес у получателя»/2-часовые интервалы),
  оплата частями (Сплит/Долями — информеры), мобайл: 2 колонки + липкая панель.
- Админка (#admin): Kanban 6 статусов с drag-and-drop (мгновенное сохранение), таблица,
  печатная записка флористу (А5: раскладка цветов, адрес, интервал, крупное пожелание, «СЮРПРИЗ»),
  WhatsApp из карточки со статус-зависимым шаблоном, тумблер «В наличии» = мгновенное
  скрытие с витрины, инлайн-цены, форма букета с мультизагрузкой фото, no-code настройки
  (контакты/баннеры/hero/порог доставки) — витрина обновляется без перезагрузки.

## Legacy

PHP-эра (`*.php`, `includes/`, `admin/*.php`) и v2026 (статическая витрина S1 + content.json
+ admin.html) сохранены в этом же репо. Прод-деплой SpaceWeb (.github/workflows/deploy.yml)
синхронизирует только legacy-файлы — S2 в rsync исключён, пока владелец не примет решение
о переезде на Node-хостинг.
